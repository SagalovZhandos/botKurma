# Бот для чата друзей 🇰🇿

Telegram-бот, который:

- **в полночь меняет название группы** на день недели по-казахски: Дүйсенбі, Сейсенбі, Сәрсенбі, Бейсенбі, Жұма, Сенбі, Жексенбі;
- **каждое утро (08:00) присылает сводку**: погода и качество воздуха в Алматы, Астане и Актобе, курс Нацбанка, праздник дня, «в этот день в истории» и мысль дня (Абай, казахские пословицы, философы);
- **поздравляет с днями рождения** и напоминает о них за 3 дня;
- **ведёт себя как умный друг в чате**: читает все сообщения, отвечает всегда, когда его зовут (упоминание, ответ на его сообщение, `/ask`), и иногда сам вставляет реплику, если есть вопрос, спор или повод пошутить. В личные разговоры и обычную болтовню не лезет. Как часто вмешиваться, задаётся командой `/mode`: `выкл`, `тихо`, `обычно` или `активно`;
- **рисует картинки**: `/img кот-космонавт на коне` или «нарисуй …»;
- **игры**: `/poll`, `/who`, `/coin`, `/dice`, `/random`, `/choose`, `/shar`.

Всё бесплатно: погода, воздух, курсы и история берутся из открытых API без ключей, для AI и картинок нужны два бесплатных ключа.

---

## Шаг 1. Создать бота

1. Откройте [@BotFather](https://t.me/BotFather), выполните `/newbot` и сохраните **токен**.
2. Добавьте бота в группу.
3. Сделайте бота **администратором** с правами:
   - «Изменение профиля группы»: без него бот не сможет менять название;
   - «Удаление сообщений»: так он будет убирать служебное «бот изменил название».

## Шаг 2. Получить бесплатные ключи

| Что | Где | Зачем |
|---|---|---|
| Groq API key | [console.groq.com/keys](https://console.groq.com/keys), вход через Google/GitHub | AI-ответы (GPT-OSS 120B), бесплатный лимит большой |
| Pollinations key (`sk_…`) | [enter.pollinations.ai](https://enter.pollinations.ai), вход через GitHub → Secret key | картинки и запасной AI |

## Шаг 3. Заполнить список друзей

В `friends.json` (формат в `friends.example.json`):

```json
{
  "friends": [
    { "name": "Айдос", "username": "aidos_kz", "birthday": "15.03.1998" },
    { "name": "Дана",  "username": "dana",     "birthday": "02.11" }
  ]
}
```

Год рождения необязателен. Если он указан, бот напишет, сколько исполняется лет. Список используется для дней рождения и для `/who`.

В `friends.json` личные данные друзей, поэтому он в `.gitignore` и в репозиторий не попадёт. На Render его добавляют отдельно как Secret File (см. шаг 4).

## Шаг 4. Запустить на бесплатном хостинге (Render)

1. Загрузите папку в **приватный** репозиторий на GitHub. Файл `.env` туда не попадёт, он в `.gitignore`.
2. На [render.com](https://render.com) выберите **New → Blueprint** и укажите репозиторий. Render прочитает `render.yaml` и создаст бесплатный Web Service.
3. Во вкладке **Environment** задайте:
   - `TELEGRAM_BOT_TOKEN`: токен из шага 1;
   - `AI_API_KEY`: ключ Groq;
   - `POLLINATIONS_TOKEN`: ключ Pollinations;
   - `CHAT_IDS`: пока оставьте пустым.

   Там же в разделе **Secret Files** создайте файл `friends.json` и вставьте содержимое своего `friends.json`. Путь `/etc/secrets/friends.json` уже прописан в `render.yaml`.
4. Когда бот запустится, напишите в группе `/chatid`. Бот пришлёт ID группы (вида `-100…`). Вставьте его в `CHAT_IDS`, Render перезапустит бота сам.
5. **Чтобы бот не засыпал.** Бесплатный Render усыпляет сервис через 15 минут без входящих запросов. Зарегистрируйтесь на [cron-job.org](https://cron-job.org) (бесплатно) и создайте задание, которое каждые 10 минут открывает `https://<имя-сервиса>.onrender.com`. Бесплатных 750 часов в месяц на Render хватает на круглосуточную работу одного сервиса.

> Если Render перезапустит бота ровно в 08:00, утренняя сводка за этот день может не прийти. Это случается редко. Её всегда можно запросить командой `/digest`. Название группы бот проверяет и при каждом запуске.

### Другие варианты запуска

- **Любой VPS или Oracle Cloud Always Free** (надёжнее, без засыпания):
  ```bash
  docker build -t friends-bot .
  docker run -d --restart unless-stopped --env-file .env --name friends-bot friends-bot
  ```
- **Свой компьютер**: та же команда Docker. Бот работает, пока компьютер включён.

## Настройки

Все настройки описаны в `.env.example`. Основные:

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `MORNING_TIME` | `08:00` | время утренней сводки |
| `TITLE_TEMPLATE` | `{day}` | шаблон названия: `{day}` даёт Жұма, `{day_ru}` даёт Пятница, `{date}` даёт 30.10. Пример: `Достар \| {day}` |
| `CITIES` | Алматы, Астана, Актобе | `Город:широта:долгота;…` |
| `BIRTHDAY_REMIND_DAYS` | `3` | за сколько дней напоминать (0 — не напоминать) |
| `ADMIN_IDS` | — | кто может вызывать `/settitle` |

## Команды

| Команда | Что делает |
|---|---|
| `/ask вопрос` | спросить AI (или упомяните бота, или ответьте на его сообщение) |
| `/img запрос` | нарисовать картинку |
| `/reset` | AI забывает историю разговора |
| `/weather` `/air` `/rates` `/today` `/quote` | отдельные части сводки |
| `/digest` | вся утренняя сводка прямо сейчас |
| `/birthdays` | ближайшие дни рождения |
| `/poll Вопрос \| Вариант 1 \| Вариант 2` | опрос |
| `/who платит за кофе` | случайный друг |
| `/coin`, `/dice` (или `/dice 🎰`), `/random 1 100`, `/choose пицца, суши или плов`, `/shar` | мини-игры |
| `/chatid` | показать ID чата |
| `/settitle` | сменить название прямо сейчас |

**О приватности.** Бот хранит последние ~40 сообщений чата только в памяти: на диск они не пишутся и после перезапуска исчезают. Когда бот отвечает или решает, вмешаться ли, эти сообщения уходят в Groq для генерации ответа. Предупредите об этом друзей.

Бот получает все сообщения, потому что он администратор группы. Если снять с него права админа, отключите ему режим приватности: в @BotFather `/setprivacy`, затем Disable.

Ботом могут пользоваться только группы из `CHAT_IDS` и их участники в личке, чтобы посторонние не расходовали лимиты AI.

```bash
docker run --rm -v "$PWD:/app" -w /app python:3.12-slim sh -c "pip install -q -r requirements-dev.txt && pytest --cov"
```

## Источники данных

Погода и качество воздуха: [Open-Meteo](https://open-meteo.com) (модель CAMS: это расчёт, а не показания станций, поэтому возможна разница с IQAir). Курсы: [Нацбанк РК](https://nationalbank.kz). «В этот день»: Википедия. AI: Groq. Картинки: Pollinations.
